> Набори продуктів для імпровізації, коли тижневий план не підходить або потрібна заміна.

***
- **Сніданки**
    - Яєчний
        - яйця
        - огірки / помідори / цибуля / болгарський перець / суміш для яєчні
        - цільнозерновий хліб
    - Вівсяний
        - вівсянка
        - протеїн / йогурт
        - банан / яблуко / ягоди
    - Молочний
        - творог
        - грецький йогурт
        - банан / яблуко / груша / ягоди
- **Обіди (м’ясо/база)**
    - Курка (філе / серця)
        - рис / гречка / булгур / макарони
        - овочі (капуста (білокачанна, броколі, цвітна) / огірки / помідори / суміші)
    - Свинина
        - картопля / рис / гречка
        - квашена капуста / салат
    - Бобово-м’ясні
        - курка / серця
        - квасоля / сочевиця / нут
        - овочі
- **Вечері**
    - Рибні
        - тунець / скумбрія / хек
        - картопля
        - цибуля / капуста / огірки
    - Легкі молочні
        - творог / грецький йогурт
        - фрукти (банан / яблуко / ягоди)
    - М’ясо + бобові
        - свинина / курка
        - нут / квасоля / сочевиця
        - овочі
- **Перекуси**
    - Білкові
        - протеїн
        - йогурт
        - творог
    - Фруктові
        - банан
        - яблуко
        - груша
        - апельсин
        - ягоди
