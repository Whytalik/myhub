В неділю здійснюється закупка і підготовка білкових продуктів на весь тиждень.

## М'ясний міл-преп (неділя)

Маринуємо все м'ясо в неділю, фасуємо по порціях і кладемо в морозилку або холодильник на тиждень.

Порції на людину: ~200 г м'яса / прийом (однакові для обох). Див. → [[Профілі]]

| М'ясо | Кількість | Маринад |
| ----- | --------- | ------- |
| Куряче стегно / філе (шашлики — Пн) | 800 г | [[Йогуртово-лимонний]] |
| Курячі серця (Вт) | 600 г | [[Соєво-томатний]] |
| Куряче стегно / філе (смажена курка — Чт) | 680 г | [[Соєво-часниковий]] |
| Куряче філе (запечене — Пт + Цезар Сб) | 1200 г | [[Медово-гірчичний]] |
| Свиняча відбивна (Нд) | 600 г (~4 шт) | [[Цитрусово-розмариновий]] |

## Алгоритм неділі (~40 хв активно)

**Блок 1 — Маринування (~20 хв)**
1. Дістати все м'ясо, розкласти на столі. Підготувати 5 мисок
2. Серця промити, натискаючи пальцями — видалити залишки крові
3. Відбивну накрити плівкою і відбити молотком з обох боків
4. Куряче стегно для шашликів нарізати шматками 2–3 см
5. Зробити всі маринади і замаринувати м'ясо поспіль:
	- [[Йогуртово-лимонний]] → стегно для шашликів → перемішати → в холодильник
	- [[Соєво-томатний]] → серця → перемішати → в холодильник
	- [[Соєво-часниковий]] → стегно/філе для смаження → перемішати → в холодильник
	- [[Медово-гірчичний]] → куряче філе → перемішати → в холодильник
	- [[Цитрусово-розмариновий]] → відбивна → перемішати → в холодильник

**Блок 2 — Поки м'ясо маринується (~20 хв активно)**
6. [[Корейська морква]]: натерти моркву → посолити → залишити на 10 хв
7. Поки морква стоїть: [[Сирники]] — розім'яти творог → замісити тісто → сформувати 10 шт
8. Повернутись до моркви: віджати → влити розігріту олію → спеції, часник, оцет → в холодильник на ніч
9. [[Сирники]]: замісити тісто → сформувати 10 заготовок → на дошку в морозилку (смажити свіжими перед прийомом)

**Фінал**
10. М'ясо розфасувати по контейнерах за днями, підписати — в холодильник або морозилку

> [[Корейська морква]] готується в п'ятницю вранці перед основним приготуванням.
