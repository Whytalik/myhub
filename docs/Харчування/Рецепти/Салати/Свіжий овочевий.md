#рецепт/салат

**Інгредієнти (1 порція):**
- Помідор — 1–2 шт (кубиками або часточками)
- Огірок — 1 шт (кільцями або кубиками)
- Зелена цибуля або цибуля — за смаком
- Зелень — петрушка, кріп (жменя)

**Заправка (на вибір):**
- Варіант 1: 1 ч.л. оливкової олії + лимонний сік + сіль
- Варіант 2: 1 ч.л. соняшникової олії + оцет + сіль + цукор
- Варіант 3: сметана або йогурт + часник + кріп

**Приготування:** Нарізати → заправити → одразу подавати.
