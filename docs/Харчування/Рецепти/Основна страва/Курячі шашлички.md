#рецепт/основна-страва

> Обід + вечеря (Пн). Маринад: [[Йогуртово-лимонний]] · Соус: [[Часниково-йогуртовий]]

**Інгредієнти (2 порції):**
- Куряче філе або стегно без кістки — 400–500 г
- Дерев'яні шпажки

**Приготування:**
1. М'ясо нарізати шматками 2–3 см
2. Замаринувати за рецептом [[Йогуртово-лимонний]] — мінімум 2 год, краще ніч
3. Шпажки замочити у воді на 30 хв (щоб не горіли)
4. Нанизати шматки, не щільно
5. Розігріти духовку до 200°C
6. Запікати на решітці або деку 20–25 хв, перевернути раз посередині
7. Останні 3–5 хв — включити гриль для рум'яної скоринки

> Куряче стегно без кістки соковитіше за філе. Шматки не повинні бути надто маленькими — висохнуть.
