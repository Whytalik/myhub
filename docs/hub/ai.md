# AI-асистент — Hub

## Як використовувати

AI-асистент доступний на кожній сторінці — кнопка ✨ у правому нижньому куті.

### Два режими роботи

**1. Чат** — пиши запити природною мовою, AI відповідає і може виконувати дії.

**2. Пропозиції** — AI аналізує поточний стан і пропонує дії, які ти можеш прийняти або відхилити.

### Домени

Перемикач у заголовку чату:
- **Ops** — завдання, спринти, цілі, проекти
- **Health** — звички, щоденник, сон, енергія

## Що AI НЕ може робити ❌

| Не працює | Чому |
|---|---|
| Видаляти дані | Безпечно — тільки створення та оновлення |
| Редагувати продукти чи страви | Домен їжі не підключений |
| Керувати бібліотекою | Домен бібліотеки не підключений |
| Керувати мовами | Домен мов не підключений |
| Надсилати повідомлення | Немає такої дії |
| Відповідати на загальні питання без контексту | AI заточений під Hub, а не чат-бот |

## Як зменшити витрату токенів

### Що вже оптимізовано

| Оптимізація | Економія |
|---|---|
| Короткі промпти з прикладами замість довгих інструкцій | ~60% |
| Історія обмежена 10 останніми повідомленнями | ~40% |
| Стиснення старої історії в короткий підсумок | ~30% |
| Безкоштовна модель `gemma-3-12b-it:free` | 100% безкоштовно |
| Обмеження відповіді до 500 токенів для чату | Запобігає розгону |
| Автоматичне обрізання історії до 40 повідомлень | Запобігає накопиченню |

### Що ти можеш робити

1. **Короткі запити** — «Додай задачу Х» замість «Будь ласка, створи для мене нову задачу з назвою Х»
2. **Один запит — одна дія** — не проси створити 5 задач в одному повідомленні
3. **Не флудь** — кожне повідомлення = новий запит до API
4. **Вимикай чат** коли не потрібен — пропозиції генеруються тільки при відкритті
5. **Очищуй історію** — кнопка 🗑️ у заголовку, якщо чат став занадто довгим

### Статистика витрат

У заголовку чату видно:
- **req** — кількість запитів за 7 днів
- **tok/req** — середня кількість токенів на запит

Натисни 📊 для детальної статистики:
- Усього запитів
- Усього токенів
- Середня кількість токенів на запит

| Ліміт | Значення |
|---|---|

3. Платні моделі — дешеві, від $0.01 за запит

## Як покращити AI

### 1. Додати новий домен

Додай нову дію в `ai-service.ts` у функції `executeSuggestion()`:

```typescript
case "createProduct": {
  const { createProduct } = await import("@/features/food/services/...");
  const result = await createProduct(userId, { ...payload });
  await prisma.aISuggestion.update({ where: { id: suggestionId }, data: { status: "ACCEPTED" } });
  return result;
}
```

І додай опис дії в `ai-prompts.ts`:

```
### createProduct
Створити продукт. Параметри: { name, category?, calories?, protein?, fat?, carbs? }
```

### 2. Покращити промпти

Файл: `src/lib/ai/ai-prompts.ts`

- Додай більше прикладів «вхід — вихід»
- Вкажи конкретні правила для свого випадку
- Зроби промпт коротшим — менше токенів

### 3. Змінити провайдера та модель

Файл: `src/lib/ai/ai-client.ts`

```typescript
export function getChatModel(): AIModelConfig {
  return {
    provider: "groq", // "groq", "google" або "openrouter"
    model: "llama-3.3-70b-versatile",
    maxTokens: 500,
    temperature: 0.3,
  };
}
```

#### Доступні провайдери:

| Провайдер | Переваги | Моделі | Ключ у .env |
|---|---|---|---|
| **Groq** | Блискавична швидкість | `llama-3.3-70b-versatile`, `llama-3.1-8b-instant` | `GROQ_API_KEY` |
| **Google** | Надійний JSON, розум | `gemini-1.5-pro`, `gemini-1.5-flash` | `GEMINI_API_KEY` |
| **OpenRouter** | Універсальність | `google/gemma-3-4b-it:free`, `meta-llama/llama-3.1-8b-instruct:free` | `OPENROUTER_API_KEY` |

### 4. Додати JSON режим

OpenRouter підтримує `response_format: { type: "json_object" }`. Додай це в `callOpenRouter()` в `ai-client.ts`:

```typescript
body: JSON.stringify({
  model: config.model,
  messages,
  response_format: { type: "json_object" },
  // ...
})
```

Це змусить модель завжди повертати валідний JSON.

### 5. Навчити AI на своїх даних

Чим більше AI бачить твоїх даних (завдання, звички, спринти), тим кращі пропозиції генерує. Контекст у `generateSuggestions()` включає:
- Активний спринт з цілями
- Кількість задач за статусами
- Активні звички
- Сьогоднішній запис (енергія, настрій, сон)

## Змінні оточення

```env
OPENROUTER_API_KEY="твій_ключ_тут"
```

Отримати безкоштовний ключ: https://openrouter.ai/keys

### Як отримати ключ

1. Зайди на https://openrouter.ai
2. Зареєструйся через Google/GitHub
3. Перейди в **Keys** → **Create Key**
4. Скопіюй ключ
5. Встав в `.env` як `OPENROUTER_API_KEY`

### Безкоштовні моделі

OpenRouter має багато моделей з позначкою `:free` — вони повністю безкоштовні:

- `google/gemma-3-12b-it:free` — поточна модель (за замовчуванням)
- `meta-llama/llama-3.1-8b-instruct:free` — альтернатива
- `mistralai/mistral-7b-instruct:free` — швидка і легка

Щоб змінити модель, відредагуй `src/lib/ai/ai-client.ts`.
