# 🚨 SOS Triggers (Маркери Кризи)

**Правило активації Crisis Mode:** Якщо я спостерігаю **2 або більше** маркерів із цього списку протягом 48 годин — я зобов'язаний зупинити звичайний ритм і перейти на Етап 0 (Survival Mode). Жодних виправдань.

## 🔴 Фізичні маркери (Тіло)
- [ ] Сон менше 6 годин протягом 3-х ночей поспіль.
- [ ] Прокидаюся вже втомленим, незалежно від тривалості сну.
- [ ] Харчування збилося: пропускаю прийоми їжі або їм тільки "швидкі вуглеводи" (снеки/солодке) весь день.
- [ ] Відчуття "важкого тіла", фонова нудота або стиснення в грудях без фізичних причин.

## 🟡 Когнітивні маркери (Мозок)
- [ ] Дивлюся в екран 30+ хвилин, не маючи сил почати навіть просту задачу ("Brain Fog").
- [ ] Безцільне, механічне перемикання між вкладками, додатками чи соцмережами.
- [ ] Різка дратівливість на дрібниці (дрібна помилка викликає бажання все кинути).
- [ ] Забуваю очевидні речі або не можу втримати в голові мету дії.

## 🔵 Поведінкові маркери (Дії)
- [ ] Повна ізоляція: уникаю будь-якого спілкування (навіть онлайн) більше 2-х днів.
- [ ] Скасовую плани чи домовленості без вагомої причини, просто бо "немає сил".
- [ ] Уникаю відкривати свій Hub/Трекери/Фінанси, бо реальність лякає.
- [ ] **"Млява манія" (False Stability):** Раптовий імпульс взяти на себе 10 нових проєктів о 2-й ночі після тижня апатії (це передвісник глибокого падіння).
