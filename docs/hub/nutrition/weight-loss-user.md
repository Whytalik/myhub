# 🎯 План схуднення (90кг → 75кг)
*Ваш особистий план. Параметри: 180 см / 90 кг / 21 рік.*

## 🔢 Розрахунок
| Показник | Значення | Опис |
| :--- | :--- | :--- |
| **BMR** | ~1950 ккал | Базовий обмін речовин. |
| **TDEE** | ~3000 ккал | Підтримка (3 рази зал + 3 рази біг). |
| **ВАШ ЛІМІТ** | **1700 ккал** | Суворий дефіцит для максимального темпу. |

## ⚠️ Увага (Агресивний дефіцит)
При 6 тренуваннях на тиждень ліміт 1700 ккал створює дефіцит ~1300 ккал. 
- **Ризик:** Можлива швидка стомлюваність та втрата м'язової маси.
- **Рішення:** Тримайте білок на максимумі (180г+) та слідкуйте за самопочуттям. Якщо вага падає швидше ніж на 1.5 кг/тиждень — додайте 200 ккал.

## 🥗 Макронутрієнти (БЖВ)
- **Білки: 180г – 190г** (Обов'язково!).
- **Жири: 60г – 65г**.
- **Вуглеводи: 100г – 120г**. Пріоритетно навколо тренувань.

## 💡 Поради
- В дні бігу додавайте +20г вуглеводів перед пробіжкою.
- Кожен прийом їжі починати з білка.
- Раз на 3 тижні — 2 дні "рефіду" (2600 ккал).
- Сон 7-8 годин (жироспалювання відбувається уві сні).
