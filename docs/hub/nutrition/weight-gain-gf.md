# 🌸 План набору ваги (52кг → 60кг)
*План для дівчини. Параметри: 170 см / 52 кг / 21 рік.*

## 🔢 Розрахунок
| Показник | Значення | Опис |
| :--- | :--- | :--- |
| **BMR** | ~1320 ккал | Базовий обмін. |
| **TDEE** | ~2100 ккал | Підтримка з урахуванням бігу. |
| **ЦІЛЬ** | **2200 - 2400 ккал** | Профіцит для набору маси. |

## 🥗 Макронутрієнти (БЖВ)
- **Білки: 75г – 85г** (~1.5г на кг).
- **Жири: 60г – 65г** (**Критично!** Не опускати нижче 55г).
- **Вуглеводи: 330г – 360г**. Основна маса калорій.

## 💡 Лайфхаки для набору
- **"Плюс 1 ложка":** +1 ст.л. олії в кашу/салат (+100 ккал).
- **Рідкі калорії:** Смузі (Йогурт + Банан + Овес + Арахісова паста) = 500+ ккал.
- **Після бігу:** Обов'язково вуглеводи + білок.
