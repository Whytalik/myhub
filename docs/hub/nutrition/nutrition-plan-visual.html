🥣 Варіанти Йогуртового Сніданку

База: 250г Грецький йогурт + 80г Ягоди. Обери свій смак ↓
🫐
Чорниця + Мед
80г чорниці (заморозка/свіжа) + 1 ч.л. меду. Антиоксиданти, солодко.
🍒
Вишня + Мед
80г вишні (кісточку прибрати) + 1 ч.л. меду. Кисло-солодкий, насичений.
🍓
Малина/Полуниця + Мед
80г малини/полуниці + 1 ч.л. меду. Класика, дуже ароматно.
🍇
Смородина/Ожина + Мед
80г смородини/ожини + 1 ч.л. меду. Терпкий смак, вітамін С.
🍌
Мікс ягід + Банан
50г будь-яких ягід + ½ банана. Найситніший варіант.
🥜
Ягоди + Горіхи
80г ягід + 10г горіхів (волоські/мигдаль). Хрустко + корисні жири.

🥘 Недільний Prep (~45 хв)

🧊 = заморозка з маринадом  ·  📦 = холодильник
🍗
Куряче філе (нарізане + мариноване)
2.5 кг → нарізати, розкласти по порціях, залити маринадом дня → 🧊 морозилка
↳ Ввечі перекласти наступний день в холодильник
🥩
Яловичина/Риба (нарізана + маринована)
1.5 кг → порції на Вт/Сб/Чт → 🧊 морозилка
↳ Розморожується в холодильнику одночасно з маринуванням
🧂
Маринади (змішані)
На весь об'єм м'яса (4 кг) → розлити по пакетах → 🧊 разом з м'ясом
↳ Йогуртові: додати свіжий йогурт вранці
🥗
Овочі порізані/помиті
2кг мікс: помідори, огірок, зелень · 3 дні в контейнері
↳ Пн–Ср — сніданки/вечері

🥩 Маринади — наносять перед готовкою, маринують від 15 хв до ночі

🐟 риба  ·  🥩 м'ясо
🥩🐟
Соєво-часниковий
2 ст.л. соєвого соусу + 2 зубці часнику + 1 ч.л. паприки
Курка на сковорідці — утворює скоринку
🥩🐟
Лимонно-трав'яний
сік 1/2 лимона + орегано + чорний перець + 1 ч.л. олії
Курка або риба в духовці. Легкий, без зайвих калорій
🥩🐟
Йогуртово-каррі
2 ст.л. йогурту + 1 ч.л. каррі + щіпка куркуми
Overnight маринад — м'ясо виходить дуже м'яким
🥩🐟
Гірчично-медовий
1 ч.л. діжонської гірчиці + 1 ч.л. меду + 1 ч.л. олії
Маринувати від 15 хв. Добре тримає вологу при запіканні
🥩🐟
Пряний томатний
1 ст.л. томатної пасти + часник + орегано + щіпка чилі
Яловичина і курка — дає насичений колір і смак

🧂 Соуси — подають готовими, поливають або мішають

🐟 риба  ·  🥩 м'ясо  ·  🥗 салат/боул  ·  🍝 паста/крупи
🐟🥩🥗
Лимонно-часниковий
сік 1/2 лимона + 2 зубці часнику (тертих) + 1 ч.л. олії + сіль + перець
Класика. Підсилює будь-який білок, не перебиває смак
🐟🥩🥗
Тахіні-лимонний
1 ч.л. тахіні + сік 1/4 лимона + 1 ст.л. води + щіпка часнику
Ближньосхідний. Кремовий, ситний (+45 ккал)
🥩🐟🥗
Чімічурі
пучок петрушки + 2 зубці часнику + 2 ст.л. олії + 1 ст.л. оцту + чилі + сіль
Аргентинський. Яскравий трав'яний — топ до м'яса на грилі та риби
🥩🐟🥗
Цацікі
3 ст.л. йогурту + 1/2 огірка (тертий, віджатий) + 1 зубець часнику + кріп + сік лимона
Грецький. Освіжає, добре до запеченого м'яса, риби і як дип
🐟🥗🍝
Понзу (соєво-цитрусовий)
2 ст.л. соєвого соусу + сік 1/2 лимона або лайма + 1 ч.л. меду
Японський. Легкий, кислувато-солоний — ідеал для риби та нудної гречки
🐟🥩🥗
Тайський дресінг
сік 1 лайма + 1 ст.л. соєвого соусу + 1 ч.л. меду + часник + щіпка чилі
Кисло-гострий, дуже ароматний — до риби, курки, будь-якого салату
🥗🍝
Лимонно-оливковий
1 ч.л. олії + сік 1/4 лимона + сіль + перець
Базовий дресінг для салату. Мінімум калорій (+40 ккал)
🥗🐟🍝
Йогурт з кропом
2 ст.л. йогурту + кріп + 1 зубець часнику
Легкий кремовий. До риби та свіжих салатів (+25 ккал)
