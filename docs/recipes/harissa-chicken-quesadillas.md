# Harissa Chicken Quesadillas

_12 порцій · заявлено ≈502 ккал / 53г білка / 50г вугл / 10г жиру на кесадилью_
_⚠️ за перевіркою нутриціолога реальні цифри ближче до ~370-390 ккал / ~38-40г білка / ~26-33г вугл / ~9-11г жиру — див. нотатки нижче_

## Курка 🍗

- Куряча грудка без шкіри й кісток — 3.5 lb (~1590г)
- Харісса — 3 ст.л.
- Оливкова олія — 1 ст.л.
- Копчена паприка — 1 ст.л.
- Мелений кмин — 2 ч.л.
- Часниковий порошок — 2 ч.л.
- Цедра 2 лаймів
- Сік 2 лаймів
- Кошерна сіль — 2 ч.л.
- Чорний перець — 1 ч.л.

## Ананас 🍍

- Ананас, дрібно нарізаний кубиками — 3 склянки
- Мед — 2 ч.л.
- Пластівці червоного перцю — 0.5 ч.л.
- Сіль — щіпка

## Йогуртовий соус з зеленню 🥣

- Знежирений грецький йогурт — 1.5 склянки
- Сік 1 лимона
- Кінза, нарізана — 2 ст.л.
- Часник, подрібнений — 2 зубчики
- Кошерна сіль — 0.5 ч.л.

## Тортильї

- Великі low-carb тортильї — 12 шт.

## Рис (опційно, окремо)

- Довгозернистий білий або басматі рис — 2 склянки (сирого)

## Приготування

Замаринувати курку, обсмажити/запекти, нарізати. Зібрати кесадильї: тортилья + курка + ананасова сальса + йогуртовий соус, скласти навпіл, підсмажити на сухій або злегка змащеній спреєм пательні до хрусткої скоринки.

## Нотатки нутриціолога

**Макроси не б'ються з інгредієнтами** — на відміну від рецепту хот-покетів, цей набагато оптимістичніший:

|           | Заявлено | Реальна прикидка |
| --------- | -------- | ---------------- |
| Калорії   | 502      | ~360-390         |
| Білок     | 53г      | **~38-40г**      |
| Вуглеводи | 50г      | ~26-33г          |
| Жир       | 10г      | ~9-11г ✅        |

- **Жир правдоподібний** — немає сиру, лише 1 ст.л. олії на весь батч курки.
- **Білок найбільш завищений.** 3.5 lb сирої курки ÷ 12 = ~132г/порцію, що фізично не дає більше ~30г білка навіть звареним. З тортильєю й йогуртом максимум ~38-40г, не 53г. **Закладай в трекер ~38-40г, не 53г.**
- **Натрій**: 2 ч.л. кошерної солі в маринаді + солона харісса-паста + low-carb тортильї (часто 300-450мг натрію/шт., взагалі не враховані у заявлених макросах) → орієнтовно 500-800мг натрію на кесадилью. 2 штуки = 1000-1600мг (45-70% денного ліміту AHA 2300мг).
- **Плюс:** low-carb тортильї зазвичай високі за клітковиною (12-19г/шт.) — одна тортилья закриває половину денної норми (38г/добу). Лайм і ананас додають трохи вітаміну C.
- **Рис зʼїдає вуглеводний бюджет**: типова порція гарніру (~1 склянка вареного) додасть ~45г вуглеводів — майже третина денного бюджету (155г) за один прийом. Якщо додаєш рис — зменш до ½ склянки вареного (~22г вугл.) або пропусти в інші прийоми дня.
- **Готувальна нотатка**: без сиру й без жиру для смаження це радше згорнута тортилья з начинкою, ніж класична хрустка кесадилья — хрусткості з фото без спрей-олії на пательню не буде.

**Вердикт**: непогана високоефективна опція для дефіциту, якщо їсти 2 штуки як прийом їжі (~76-80г реального білка). Не довіряй заявленому білку 53г при плануванні дня.
