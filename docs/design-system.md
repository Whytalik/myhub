# 🪐 Дизайн-система "Cyber-Craft Acrylic"

**myhub** — це персональний цифровий простір користувача. Дизайн-система **Cyber-Craft Acrylic** об'єднує глибоку контрастність темних робочих інструментів розробника (у стилі Linear/Vercel) з об'ємністю матеріалу матового скла macOS (Glassmorphism) та точністю класичних терміналів (CLI).

---

## 🎨 1. Колірна палітра (Color Tokens)

Дизайн-система побудована на моделі **рівнів піднесення (Elevation Level)**. Замість використання тіней, об'єм у темному режимі досягається за допомогою ступеневої зміни яскравості фону та тонких напівпрозорих рамок.

### 🌑 Базові кольори інтерфейсу (Base Surface)

| Токен | Колір (Hex / RGBA) | Опис | Призначення |
| :--- | :--- | :--- | :--- |
| `bg-canvas` | `#08080a` | Глибокий чорний ("порожнеча") | Основне тло сторінки та всього додатка. |
| `bg-surface` | `#121214` | Темно-сірий вугільний | Фони карток, панелей, списків та таблиць. |
| `bg-elevated` | `#1c1c1f` | Світліший сірий | Спливаючі меню, модальні вікна та випадаючі списки. |
| `bg-hover` | `#232327` | Інтерактивний сірий | Колір фону елементів при наведенні миші. |
| `border-stroke`| `rgba(255, 255, 255, 0.08)` | Напівпрозорий білий | Тонкі межі (1px) для розмежування блоків. |

### 🧪 Ефект матового скла (macOS Acrylic)

Застосовується **виключно** до структурних компонентів оболонки (сайдбар, кросс-доменна шапка, модальні діалоги):

*   **Формула скла:** `backdrop-blur-md bg-surface/50 border border-white/8 shadow-2xl shadow-black/40`
*   При наведенні на скляні елементи межа стає яскравішою: `border-white/15`

### 🔵 Системні акценти (Apple System Accents)

Акцентні кольори використовуються точково — для кнопок дій (CTA), фокусу та кодування просторів:

| Простір (Space) | Токен | Hex | Бейдж (Badge) | Призначення |
| :--- | :--- | :--- | :--- | :--- |
| **Універсальний** | `color-blue` | `#007aff` | `bg-blue-500/10 text-blue-400` | Головні кнопки дії, фокус введення, активні навігаційні таби. |
| **Health space** | `color-emerald`| `#34c759` | `bg-emerald-500/10 text-emerald-400` | Секція тренувань, харчування, успішно виконані цілі. |
| **Life space** | `color-orange` | `#ff9500` | `bg-orange-500/10 text-orange-400` | Задачі, звички, поточні таймери та фокус дня. |
| **Помилки/Дії** | `color-red` | `#ff3b30` | `bg-red-500/10 text-red-400` | Кнопки видалення, протерміновані таски, критичні повідомлення. |

## 🔠 2. Типографіка (Typography)

Типографіка розділена на два класи для поєднання зручності читання великих текстів та чіткості даних:

1.  **Sans-Serif (Geist Sans / Inter / System-UI):** Основний шрифт для інтерфейсу, заголовків, кнопок та нотаток щоденника. Має щільний міжлітерний інтервал (letter-spacing) для створення преміального відчуття.
2.  **Monospace (Geist Mono / JetBrains Mono):** Використовується для будь-яких числових даних, часу, статусів, прогрес-барів та коду.

### Шкала розмірів:

*   `text-page-title` — `1.5rem (24px) | Bold | tracking-tight` (Назва сторінки)
*   `text-panel-title` — `1.125rem (18px) | SemiBold` (Заголовки карток та секцій)
*   `text-body` — `0.9375rem (15px) | Regular | line-height: 1.6` (Основний контент)
*   `text-caption` — `0.8125rem (13px) | Medium | text-text-secondary` (Підписи, метадані)
*   `text-label` — `0.75rem (12px) | Bold | Monospace | uppercase` (Бейджі, статуси, мітки форм)

## 📐 3. Відступи та Радіуси (Spacing & Rounding)

### Скруглення кутів (Rounded):
*   `rounded-2xl` (16px) — Картки, спливаючі модальні панелі, великі блоки.
*   `rounded-lg` (8px) — Кнопки, поля введення, випадаючі селектори, дрібні віджети.
*   `rounded-full` (9999px) — Чіпси, круглі бейджі, аватари.

### Відступи (Spacing Grid):
Використовується крокова 4px-сітка:
*   `space-1` (4px) / `space-2` (8px) — Внутрішні мікро-відступи (мітка + інпут).
*   `space-4` (16px) — Внутрішній padding елементів карток.
*   `space-6` (24px) / `space-8` (32px) — Відступи між картками та великими розділами сторінок.

## 🧱 4. Керівництво щодо компонентів (Component Guidelines)

### 🔘 Кнопка (`Button`)
*   **Primary:** Суцільний акцентний колір (`bg-blue-500 text-white`). Ефект легкого масштабування при натисканні (`active:scale-98`).
*   **Secondary:** Сірий фоновий тон (`bg-surface`) з напівпрозорою межею. Стає світлішим на ховері.
*   **Danger:** Напівпрозорий червоний фон з червоною межею, або яскраво-червоний для критичних CTA.
*   **Ghost/Icon:** Повністю прозорий фон. З'являється `bg-hover` лише при наведенні.

### 📝 Поля введення (`Input` / `Textarea`)
*   Мають чистий темний фон (`bg-canvas/50 border border-white/8 rounded-lg`).
*   При фокусі плавно підсвічуються межею акцентного кольору простору та набувають легкого внутрішнього світіння.
*   Усі плейсхолдери виводяться приглушеним кольором `text-text-muted`.

### 🟦 Чекбокс (`Checkbox`)
*   Кастомний примітив. У неактивному стані — порожній квадрат із тонкою рамкою.
*   При виборі плавно заповнюється акцентним кольором і відображає галочку.

## 🎨 5. Приклади використання (Do's & Don'ts)

✅ **РЕКОМЕНДУЄТЬСЯ (Do):**
*   Використовувати моноширинний шрифт для відображення прогресу (наприклад, `font-mono 8/10`).
*   Створювати ієрархію між шарами за допомогою фонів (`bg-canvas` -> `bg-surface` -> `bg-elevated`).
*   Додавати плавні транзиції для всіх ховерів (`transition-all duration-150`).

❌ **ЗАБОРОНЯЄТЬСЯ (Don't):**
*   Використовувати різнокольорові іконки (всі іконки мають бути одноколірними та відповідати кольору тексту поруч).
*   Малювати важкі розмиті тіні навколо звичайних карток на сторінці (користуйтеся рамками).
*   Змішувати більше ніж два акцентні кольори в межах однієї секції.
